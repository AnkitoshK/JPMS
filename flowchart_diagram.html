Job Portal Management System (JPMS)

Platform Workflow Flowcharts

1. Job Application & Interview Scheduling Flowchart

flowchart TD A[Jobseeker browses /jobs] --> B{Authenticated?} B -- No --> C[Redirect to /jobseeker-login with return URL] B -- Yes --> D[Click Apply on Job] D --> E[Fill Cover Letter & Attach/Select Resume] E --> F[Submit Application via POST /api/applications] F --> G[DB stores application with status = 'pending'] G --> H[Admin logs into Admin Dashboard] H --> I[Admin opens Application Management] I --> J{Admin Action} J -- Review --> K[Status updated to 'under_review' or 'shortlisted'] J -- Schedule Interview --> L[Admin inputs Date, Time, Meeting Link & Notes] L --> M[DB updates status = 'interview_scheduled'] M --> N[Nodemailer dispatches HTML Email to Jobseeker] N --> O[Jobseeker receives email & sees interview details in /applied-jobs timeline] J -- Reject --> P[Status updated to 'rejected' & optional email sent] J -- Offer Job --> Q[Status updated to 'offered' & offer email sent]

2. Authentication & JWT Token Flowchart

flowchart TD A[User enters credentials] --> B[POST /api/auth/login] B --> C{Rate limit exceeded?} C -- Yes --> D[Return 429 Too Many Requests] C -- No --> E[Query DB for user email] E --> F{User exists?} F -- No --> G[Return 401 Invalid Credentials] F -- Yes --> H[Verify password using bcrypt.compare] H -- Invalid --> G H -- Valid --> I[Generate JWT token with role & expiration] I --> J[Return token & user profile object JSON] J --> K[Client stores token in localStorage & AuthContext] K --> L[Axios Interceptor attaches Bearer token to all future requests] L --> M{Backend validates token} M -- Token Expired / Invalid --> N[Return 401 Unauthorized] N --> O[Client Interceptor catches 401 -> clears storage -> redirects to login] M -- Valid Token --> P[Process request successfully]
